`/admin-preview` is a real-data staging route by default. Synthetic data and browser-only operations require the explicit test-only build variable `VITE_ADMIN_DEMO=1`. Connected mutations call Fastify with CSRF, RBAC and step-up handling; every unconnected mutation remains disabled rather than simulated.


## List transport

Customers, services, orders, invoices, transactions, subscriptions, refunds, jobs, tickets, staff and audit use server-side search (`q`), offset paging (`limit`/`offset`, with `total`) and, where the route supports them, filters (`type`/`status` on jobs, `status` on tickets). Large datasets are never filtered in the browser. Detail joins still arrive as separate collections inside each detail payload.
