### Button

The base action. Every other action component (groups, split, menus) is built from it.

- **Use for:** primary, secondary, ghost, ink, lime, subtle, danger, danger-subtle, sm / md / lg, block, loading, disabled, with icons
- **Props:** variant: ButtonVariant; size: sm | md | lg; loading?: boolean; loadingLabel?: string; leadingIcon? / trailingIcon?: IconName; block?: boolean
- **Accessibility:** Native button semantics via Base UI. Loading sets aria-busy, keeps focus and ignores clicks. Disabled buttons stay reachable with focusableWhenDisabled when loading.
- **Responsive:** Heights follow --ctl-sm/md/lg tokens (44px default touch target). Density compact reduces them.

### Badge and StatusBadge

Badge labels static things. StatusBadge shows state that changes: one look for server, invoice, domain, job and ticket state, with caller-supplied meaning.

- **Use for:** neutral, accent, good, warn, bad, info, violet, lime, ink, live dot
- **Props:** tone: BadgeTone; dot?: boolean; live?: boolean
- **Accessibility:** State is always carried by the text label; the dot is decorative. Live ping respects reduced motion.
- **Responsive:** Never wraps; truncate the surrounding text instead.

### Card and surfaces

Flat color-block containers. Hierarchy comes from surface tone (bg, s1, s2, s3), never borders or shadows.

- **Use for:** raised, sunken, accent, ink, lime, pad none/sm/md/lg
- **Props:** surface; pad; as
- **Accessibility:** Use as="section" with a heading for landmarks. Cards are not interactive by themselves.
- **Responsive:** Min-width 0 so content truncates instead of overflowing grids.

### Skeleton, EmptyState, Avatar, Kbd, Tooltip

Small building blocks: loading placeholders, empty and error states, identity and keyboard hints.

- **Use for:** skeleton, empty, error, avatar sizes, tooltip
- **Props:** EmptyState: icon, title, description, action, tone; Tooltip: content, side, delay
- **Accessibility:** EmptyState tone=error uses role=alert. Skeleton is aria-hidden; mark the loading region aria-busy. Tooltip opens on hover and keyboard focus.
- **Responsive:** EmptyState centers and limits line length to 44ch.

### ButtonGroup

Independent, related actions joined into one object. Server power actions are the canonical case. Not a selection control.

- **Use for:** horizontal, vertical, mixed variants per child
- **Props:** aria-label (required); orientation
- **Accessibility:** role=group with a required accessible name. Each child is a real button; Tab visits each.
- **Responsive:** Allow the group to wrap into a vertical stack with orientation="vertical" below the breakpoint you choose.

### SegmentedControl

Choose exactly one option from a small set (2 to 5). Time ranges, view modes, Quick vs Custom. Not interchangeable with ButtonGroup.

- **Use for:** sm / md, block, with icons, icon-only on mobile, disabled option
- **Props:** aria-label (required); options: {value,label,icon?,disabled?}[]; value / defaultValue / onValueChange; size; block
- **Accessibility:** role=radiogroup. Arrow keys move and select, Tab leaves the group, selected option exposed as checked.
- **Responsive:** Use block on phones. iconOnlyOnMobile keeps the label for screen readers.

### ToggleButtonGroup

Independent on/off toggles that belong together (chart series, formatting).

- **Use for:** multiple, icon only
- **Props:** aria-label; options; value / onValueChange; multiple
- **Accessibility:** Each toggle is a button with aria-pressed. Group has an accessible name.
- **Responsive:** Icon-only toggles keep 44px touch targets.

### SplitButton

One primary action with related alternatives behind a chevron.

- **Use for:** primary / secondary, sm / md / lg, disabled
- **Props:** children (primary label); entries: MenuEntry[]; menuLabel (required); ...ButtonProps
- **Accessibility:** Two buttons. The chevron has its own accessible name and opens a menu (arrow keys, typeahead, Escape returns focus).
- **Responsive:** Menu collides with the viewport edge and stays on screen.

### ActionMenu, DropdownButton, ContextMenu

Menus of related actions: row overflow, secondary operations, and right-click or long-press shortcuts that always mirror a visible control.

- **Use for:** items, separators, groups, checkbox items, radio items, submenu, danger tone, disabled with reason
- **Props:** entries: MenuEntry[]; trigger?; align / side
- **Accessibility:** Base UI menu: Enter, Space or ArrowDown opens, arrows move, Home/End, typeahead, Escape closes and restores focus to the trigger.
- **Responsive:** Items are 44px tall on touch. Popups collide with the viewport and scroll when taller than the space available.

### Toolbar and ResponsiveActionBar

A single tab stop for a row of controls, and an action bar that moves what does not fit into a More menu. File manager toolbars are the target use.

- **Use for:** toolbar with groups and separators, responsive overflow
- **Props:** Toolbar: aria-label; ResponsiveActionBar: actions: BarAction[] (ordered by priority)
- **Accessibility:** Toolbar uses roving focus: one Tab stop, arrow keys between controls. Overflow actions are reachable through the More menu.
- **Responsive:** ResponsiveActionBar measures a hidden copy and recomputes on resize. Resize the viewport to see actions move into More.

### BulkActionBar and FloatingActionBar

Contextual bar that appears when rows are selected, pinned above the mobile tab bar.

- **Use for:** visible / hidden, above tab bar
- **Props:** count; noun; onClear; children (actions); aboveTabBar
- **Accessibility:** region with a name. Selection count is announced politely. Hidden state is inert, so it takes no focus.
- **Responsive:** Clears the home indicator via safe-area insets and sits above the tab bar on phones.

### CopyButton, LoadingButton, DestructiveAction

Actions with consequences: copy with confirmation, async buttons that prevent double submits, and confirmed destructive operations.

- **Use for:** copy icon / with text, loading async, error surfaced, destructive with typed confirmation
- **Props:** CopyButton: value (string or async getter), label, text; LoadingButton: onClick (async), onError; DestructiveAction: title, description, confirmLabel, requireText, onConfirm
- **Accessibility:** Copy result is announced (role=status). LoadingButton sets aria-busy. The destructive dialog is an alertdialog; the typed phrase gates the confirm button and errors appear inside the dialog.
- **Responsive:** The confirmation becomes a bottom sheet below md.

### CommandButton

A shell command that copies itself on click: install snippets, connection strings. Long commands wrap.

- **Use for:** default, no prompt, long command, copy blocked
- **Props:** command; label?; prompt?; onCopied / onError
- **Accessibility:** Real button named "Copy command: <command>". Result is announced through a polite status ("Copied" / "Copy failed"). Focus ring is visible on the dark surface.
- **Responsive:** Full width; long commands wrap inside the button (break-all), so there is no horizontal scroll.

### RevealButton

Show a value on demand and hide it again after a timeout. Not for credentials (use SecretField).

- **Use for:** static value, fetched on reveal, fetch fails, auto-hide
- **Props:** what; value: string | () => Promise<string>; autoHideMs; placeholder
- **Accessibility:** aria-expanded and aria-controls point at the value output. The value is not in the DOM while hidden. Failure is an alert.
- **Responsive:** Wraps; long values break instead of overflowing.

### TextField, Textarea, SearchField, PasswordField

Text entry with label, description, error, prefix/suffix and units, in one consistent control surface.

- **Use for:** default, with icon, prefix / suffix, error, disabled, readOnly, textarea with counter, search with clear, password with reveal
- **Props:** label (required); description; error; prefix / suffix / leadingIcon; size; hideLabel
- **Accessibility:** Label is always present (hideLabel keeps it for screen readers). Description is read with the control. Error is announced and sets aria-invalid. 16px text on touch widths prevents iOS zoom.
- **Responsive:** Full width; sizes follow control tokens. Prefix and suffix never wrap.

### SecretField

A secret the user can reveal, copy or replace. The plain value is not in the DOM until revealed and is masked again after a timeout.

- **Use for:** server-side only (fetch on reveal), client-held, replace, reveal fails
- **Props:** value?; onReveal?: () => Promise<string>; onReplace?; autoHideMs
- **Accessibility:** Reveal is a toggle button with aria-pressed. Copy result is announced. Failures are shown inline, not swallowed.
- **Responsive:** Actions stay on one row; the value truncates.

### NumberField and NumberStepper

Numbers with bounds, units and safe stepping. Max players, memory, TTL.

- **Use for:** inline steppers, split stepper, unit suffix, formatted, error, disabled
- **Props:** value / defaultValue / onValueChange; min / max / step / largeStep; unit; format; steppers: none | inline | split
- **Accessibility:** Native input semantics with spinbutton behavior: arrows step, Shift steps by largeStep, Home and End jump to bounds. Values are clamped on blur; buttons have names.
- **Responsive:** Split stepper has 44px buttons for touch. Input text is 16px on phones.

### SliderField

A value where relative position matters more than the exact number.

- **Use for:** default, formatted value, disabled
- **Props:** value / defaultValue / onValueChange; min / max / step; formatValue
- **Accessibility:** Thumb is a slider with value and range announced; arrow keys, Home, End, PageUp and PageDown work.
- **Responsive:** Track height is the touch target (44px).

### Select (and GroupedSelect)

Pick one from a known list of up to about 15 options. Options with a group render under headings.

- **Use for:** flat, grouped, placeholder, error, disabled, with descriptions
- **Props:** options: Option[]; value / defaultValue / onValueChange; placeholder; size
- **Accessibility:** Base UI select: Enter/Space/ArrowDown opens, arrows move, typeahead jumps, Escape closes and restores focus.
- **Responsive:** Popup matches trigger width and collides with the viewport.

### SearchableSelect, MultiSelect, AsyncSelect, Creatable

Type-to-filter pickers: single and multiple, server-side search, and creating a missing option. For long lists such as locations, versions, users and domains.

- **Use for:** single, multiple with chips, grouped, async with loading / error / no results, creatable, max selections, clearable
- **Props:** options; value / onValueChange; loadOptions(query, signal); onCreate(label); max (multi); clearable; emptyText
- **Accessibility:** Combobox semantics from Base UI: arrows move through the list, Enter selects, Escape closes, chips are focusable and removable with Backspace/Delete. Loading and errors are announced via the status region.
- **Responsive:** Popup width follows the input and scrolls when taller than the space available. 16px input on phones.
- **Known gaps:** Virtualization for lists over a few thousand options is not wired in yet.

### Checkbox, RadioGroup, RadioCardGroup, Switch

Boolean and one-of-few choices. Cards for choices that need explanation (software, plan, region).

- **Use for:** checkbox / indeterminate / group, radio inline / stacked, radio cards (1 to 4 columns), switch with description, disabled, error
- **Props:** label / description; options: ChoiceOption[]; value / onValueChange; error
- **Accessibility:** Real checkbox, radio and switch semantics. Groups are fieldsets with legends. Radio cards use radiogroup keyboard behavior. 44px hit areas.
- **Responsive:** Cards stack to one column on phones.

### TagInput

Free-form list of short values: allowed IPs, whitelisted players.

- **Use for:** default, validated, max items, paste multiple
- **Props:** value / onValueChange; validate(tag, current); max; separators
- **Accessibility:** Add and remove are announced in a polite live region. Chips have named remove buttons; Backspace on an empty input removes the last chip.
- **Responsive:** Chips wrap; the input keeps a 28px minimum width.

### KeyValueEditor and EnvironmentVariableEditor

Structured editable rows. Environment variables get name rules, duplicate and reserved-name checks, secret masking and .env paste.

- **Use for:** key/value, environment variables, secret rows, reserved keys, paste .env
- **Props:** rows / onRowsChange; validateKey / validateValue; allowSecret; reservedKeys; pasteLines; maxRows
- **Accessibility:** Every input has an indexed accessible name. Errors are linked with aria-describedby. On narrow screens each row becomes a card instead of squeezing two inputs.
- **Responsive:** Two columns plus actions from md; stacked cards below.

### Dropzone, DateField, TimeField, FieldGroup

File input with drag and drop plus a real button, native date and time controls, a calendar picker with date ranges and presets, and fieldset grouping.

- **Use for:** dropzone single / multiple, type and size rejection, date, time, calendar date picker, date range with presets
- **Props:** Dropzone: accept, maxSizeBytes, multiple, onFiles, onReject; DateField / TimeField: label, error; DatePicker: value (YYYY-MM-DD), onValueChange, min, max; DateRangePicker: value {start,end}, presets
- **Accessibility:** Dropzone is operable without drag: the button opens the file picker. Rejections appear as an alert list. DateField and TimeField use native pickers; DatePicker is a dialog-less popover with a role=grid calendar, full spoken dates, roving focus and min/max.
- **Responsive:** Full width; the button is 34px+ and keeps a 44px hit area through padding on touch.
- **Known gaps:** TimeField stays native on purpose. Calendar is Gregorian only, week starts Monday unless set, and has no multi-month view. Not yet checked on a real touch device.

### FormWizard

Multi-step flow with per-step validation, summary aside and async submit. Base for Deploy (Quick vs Custom).

- **Use for:** stepper (desktop) / progress bar (phone), validation blocks Next, summary aside, async submit with error
- **Props:** steps: {id, title, content(ctx), validate?}; values / onChange (caller owns state); onSubmit (async ok); aside?(values); onCancel?
- **Accessibility:** Progress is a nav; current step has aria-current="step". Heading receives focus on each step change. Errors are announced by an alert and shown on fields.
- **Responsive:** Below sm the stepper becomes "Step x of y" with a bar; actions stack with the primary on top.
- **Known gaps:** Draft persistence is opt-in (persistKey, sessionStorage). No branching steps. Stepper allows jumping back only. Not covered by an automated keyboard test.

### CheckboxCardGroup

Multi-select cards for addons, channels and modes. Counterpart of RadioCardGroup.

- **Use for:** 2 columns, with icons and prices, disabled option, error
- **Props:** legend, description; options: {value,label,description,icon,meta,disabled}; value / onValueChange; columns; error
- **Accessibility:** Checkbox group inside a fieldset with a legend. Space toggles; the description is read with the option.
- **Responsive:** One column on phones, then 2-4.

### ValidationSummary

List of everything blocking a form, each linking to its field. Focus moves to it when it appears.

- **Use for:** one issue, many issues, issue without field
- **Props:** issues: {fieldId?, label, message}[]; title?; autoFocus?
- **Accessibility:** role="alert" container receives focus; each item is a link that focuses the invalid control.
- **Responsive:** Full width of the form.

### Dialog

Modal surface for forms and detail. Becomes a bottom sheet below md. Also covers the drawer placement.

- **Use for:** dialog (centered), drawer (right side), sizes sm/md/lg/xl, controlled
- **Props:** title: string; description?: ReactNode; trigger? / open? / onOpenChange?; footer?: ReactNode; placement: dialog | drawer; size; hideClose?
- **Accessibility:** Focus trap, focus returns to the trigger, Escape and outside press dismiss, scroll lock, labelled by title (Base UI).
- **Responsive:** Bottom sheet below md with full-width stacked actions.
- **Known gaps:** No swipe-to-dismiss on the bottom sheet. Not yet tested on a real touch device.

### AlertDialog

Interrupting confirmation for destructive or irreversible actions, with optional typed confirmation.

- **Use for:** default, danger, requireText, async confirm with error
- **Props:** trigger; title; description; confirmLabel; tone; requireText?; onConfirm: () => void | Promise<void>
- **Accessibility:** role=alertdialog, cannot be dismissed by outside press, focus starts on the safe choice.
- **Responsive:** Same bottom sheet behavior as Dialog.
- **Known gaps:** Not yet tested on a real touch device.

### Popover, HoverCard and Tooltip

Anchored floating content: Popover for interactive content, HoverCard for previews, Tooltip for short labels.

- **Use for:** Popover, HoverCard, Tooltip sides
- **Props:** trigger; children; side / align; Tooltip: content, delay
- **Accessibility:** Popover is focus-managed and closes on Escape. Tooltip appears on hover and keyboard focus. HoverCard is a hover enhancement only; its content must exist elsewhere for touch.
- **Responsive:** Collision-aware positioning. Never the only place critical information lives on touch.
- **Known gaps:** Not yet tested on touch devices.

### DataTable

Sortable, searchable, selectable list with pagination. Cards on phones. Used for services, domains, invoices, tickets, players.

- **Use for:** sort, global search, column picker, row selection with bulk bar, row click, loading, error, empty, no matches
- **Props:** data, columns (TanStack ColumnDef + meta), getRowId, caption; loading / error / onRetry / empty; selectable + bulkActions(selected); searchable, columnPicker, pageSize; onRowClick, mobileCard?; renderExpanded?(row), rowLabel?(row)
- **Accessibility:** Real table with caption, scope=col and aria-sort on sortable headers. Select-all and per-row checkboxes are labelled. Selection count is announced. Below md the list is a labelled ul.
- **Responsive:** Below md: cards (primary column as title, label/value pairs). Column picker is desktop-only.
- **Known gaps:** Client-side sort/filter/pagination only; no server-driven mode. No column resize or virtualization. Sticky header needs the `maxHeight` prop. Row click is keyboard-operable (rows are focusable, Enter/Space) but a real link in a cell is still the better pattern for navigation.

### Pagination

Page controls with range summary.

- **Use for:** numbered with gaps, compact on phones
- **Props:** page (0-based), pageCount, onPageChange; total?, pageSize?
- **Accessibility:** nav landmark, current page marked aria-current, summary is a polite live region.
- **Responsive:** Numbered buttons from sm; previous/next with "x / y" below.
- **Known gaps:** Not yet tested on a real touch device.

### DescriptionList, Timeline and ActivityFeed

Detail pages: facts as label/value, history as a vertical timeline, short audit feed.

- **Use for:** DescriptionList with copy, Timeline tones, ActivityFeed
- **Props:** DescriptionList: items {label, value, copy?, mono?}; Timeline: events {id, title, time, tone?, icon?}; ActivityFeed: items {actor, action, target?, time}
- **Accessibility:** Semantic dl and ol, time elements carry dateTime when provided.
- **Responsive:** Label stacks above value on phones.

### TreeView / FileTree

Hierarchy with keyboard navigation: file browsers, settings groups.

- **Use for:** expandable folders, file meta
- **Props:** nodes: TreeNode[]; label; selectedId?, onSelect?; defaultExpanded?
- **Accessibility:** role=tree with roving tabindex, aria-level, aria-expanded. Arrows, Home, End, Enter work as in the ARIA tree pattern.
- **Responsive:** 40px rows for touch.
- **Known gaps:** No drag and drop and no lazy loading of children. Type-ahead, `*` and aria-setsize/posinset are in.

### FilterBuilder

Field / operator / value rules combined with AND. applyFilters runs them on loaded rows, or send the rules to an API.

- **Use for:** text, number, select fields, incomplete rule ignored, limit reached
- **Props:** fields; rules / onRulesChange; max?; applyFilters(rows, rules, fields, getValue)
- **Accessibility:** Every control has a name like "Filter 2 operator". Remove buttons are named per rule. Active count is a status.
- **Responsive:** Rules stack on phones, four columns from sm.

### PricingTable and PlanComparison

Plan cards for choosing a plan, plus a side-by-side comparison table. Prices arrive formatted; nothing is calculated here.

- **Use for:** monthly / yearly header, highlighted plan, current plan, unavailable with reason, comparison table
- **Props:** plans: PricingPlan[]; onSelect(plan); selectLabel?(plan); header?; PlanComparison: plans, rows
- **Accessibility:** Plans are a labelled list of headings; the comparison is a real table with row and column headers, and included/not included are read as text.
- **Responsive:** One column on phones, four on xl. The comparison scrolls inside its own region.

### MetricCard

One number with context. Shows a dash and a reason when the source reported nothing; never invents a value.

- **Use for:** ready, with delta, with sparkline, loading, unavailable
- **Props:** label, value, unit, icon; state: ready | loading | unavailable; unavailableReason; delta {value, direction, goodWhen}; trend: number[] (real samples only)

- **Responsive:** Fluid in a grid; value stays on one line.

### Charts (area, line, bar, stacked)

- **Use for:** area, line, bar, stacked bar, loading, empty, error, stale, with TimeRangeSelector
- **Props:** ChartFrame: title, summary (required), state, onRetry, staleLabel, actions; TimeSeriesChart: kind, data, xKey, series, stacked, formatX/Y, domain

### ServerConsole

Live console for servers and bots using xterm.js, with a real input and command history.

- **Use for:** output + input, input disabled with reason
- **Props:** ref: write / writeln / clear / getText; onCommand(cmd); inputDisabledReason?; scrollback, height
- **Accessibility:** Output is role=log (not live-announced, to avoid flooding screen readers), focusable for keyboard scrolling. Input is a native text field.
- **Responsive:** Fits its container with ResizeObserver; input uses 16px text on phones to avoid zoom.
- **Known gaps:** The WebSocket to Pterodactyl is not part of this library: the app wires `write` and `onCommand`. No ANSI search, no tab completion. Loaded lazily (xterm chunk).

### CodeEditor and DiffViewer

Edit server.properties, JSON, YAML and scripts with CodeMirror; review changes before saving.

- **Use for:** properties / json / yaml / javascript, readOnly, unified diff
- **Props:** value, onChange, language, readOnly, label, height; DiffViewer: original, modified
- **Accessibility:** CodeMirror exposes the content as a labelled multiline textbox; Tab inserts indentation (Escape then Tab leaves the editor is NOT configured yet).
- **Responsive:** Line wrapping on by default; 14px mono.
- **Known gaps:** No keyboard trap escape hatch, no autocomplete, no linting. Diff is unified only. Loaded lazily.

### LogViewer, TaskProgress and DeploymentLog

Read build and deploy output with filters, follow mode and per-step state.

- **Use for:** filter by level and text, follow / jump to latest, steps with states
- **Props:** LogViewer: lines, label, height, follow; TaskProgress: steps {state, detail}; DeploymentLog: steps + lines
- **Accessibility:** role=log with label; steps are an ordered list with state text, not only icons.
- **Responsive:** Fluid width; log scrolls inside its own box.
- **Known gaps:** Renders up to 2000 lines without virtualization.

### FileExplorer, FileUploadQueue and Dropzone

Browse and manage server files: navigate folders, row actions, upload with progress.

- **Use for:** folders first, row actions, upload states
- **Props:** FileExplorer: path, entries, onNavigate, onOpenFile, actionsFor; FileUploadQueue: items, onCancel, onRetry
- **Accessibility:** Real table with sortable headers; folder and file names are buttons; breadcrumb navigates up.
- **Responsive:** Cards on phones via DataTable (row actions hidden there: add them to a detail sheet).
- **Known gaps:** No multi-file move/copy, drag between folders or rename-in-place. File data comes from the Pterodactyl client API, wired by the app.
